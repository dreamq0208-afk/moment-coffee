# 设计规范

## 一、整体感觉

简约、治愈、高级。像一家安静的小咖啡馆，不是一个热闹的 App。

参考过喜茶 DIY：借了"改一下，杯子马上变"和"手绘线条 + 大量留白"。没有用卡通小人，也不要加。

我们自己的记忆点有三个，别削弱它们：

1. **手绘玻璃杯**：永远在最上面，是整个页面的主角。
2. **牛皮纸杯套 + 手写留言**：情绪连接发生的地方。
3. **热敏纸小票**：用来分享的成品。

三种材质各管一件事，不要混用。比如不要把选项卡片做成牛皮纸。

## 二、颜色

| 名字 | 浅色 | 深色 | 用在哪 |
|---|---|---|---|
| 底色 | `#EDEFEA` | `#1A1816` | 页面背景，很淡的灰绿 |
| 卡片 | `#F8F8F4` | `#23201D` | 选项卡片、感受标签 |
| 主文字 | `#2B2420` | `#EFE9E1` | 标题、正文 |
| 次文字 | `#8A837A` | `#9C948A` | 说明、提示 |
| 线条 | `#D9DAD3` | `#36322D` | 描边、分隔 |
| 主按钮 | `#2E2520` | `#EFE9E1` | 按钮底色，深色模式反过来 |
| 牛皮纸 | `#DCC7A6` | 不变 | 杯套 |
| 牛皮纸上的字 | `#3D2C1E` | 不变 | 杯套留言 |
| 小票纸 | `#FCFBF8` | 不变 | 小票 |
| 改动提示点 | `#C77B4A` | 不变 | 标签上的小橙点，全站唯一的强调色 |

规矩：

- 页面上的彩色只来自咖啡本身和小料。界面控件保持黑白灰。
- 不要加渐变装饰，不要加彩色阴影。
- 牛皮纸和小票在深色模式下不变色，它们是"实物"。

## 三、字体

| 用途 | 字体 | 字重 |
|---|---|---|
| 标题、咖啡名字、店名 | 思源宋体（Noto Serif SC） | 600 |
| 正文、按钮、选项 | 思源黑体（Noto Sans SC） | 300 / 400 / 500 |
| 杯套留言、心情回响 | 马善政毛笔楷书（Ma Shan Zheng） | 400 |
| 小票 | JetBrains Mono + 思源黑体 | 400 |

规矩：

- 标题不要用太粗的字重，600 就够了。粗了就不高级。
- 不要全大写标签，不要在标题里单独给某个词换颜色。
- 手写体只用在"咖啡师说话"的地方。别处不用。

## 四、布局

- 手机优先，内容最大宽度 440px，左右留 22px。
- 单列，居中对齐为主。点单页的问题标题左对齐。
- 留白要大方。宁可少放东西，也不要挤。
- 修改页底部按钮固定，要避开手机底部的安全区。

## 五、形状

| 元素 | 圆角 |
|---|---|
| 主按钮、次按钮、感受标签 | 胶囊（999px） |
| 选项卡片 | 16px |
| 电量电池 | 10px |
| 杯套 | 3px，微微倾斜 −1° |
| 小票 | 直角，上下锯齿边 |

不同层级用不同圆角，不要一个圆角用到底。

## 六、动效

只有一个"重头戏"：**倒咖啡**。其余都要克制。

| 场景 | 效果 | 时长 |
|---|---|---|
| 倒咖啡 | 从杯口倒下一股细流，液面一层层上涨 | 约 2.6 秒 |
| 出杯后 | 冰块、小料淡入；热饮冒三缕热气，循环 | 0.35 秒 |
| 修改时 | 液体层平滑变厚、变薄、变色 | 约 0.45 秒 |
| 进入修改 | 杯子从 210px 缩到 150px | 约 0.45 秒 |
| 结果页内容 | 名字、杯套、小票依次浮现 | 0.6 秒 |
| 杯套留言 | 一个字一个字写出来，换行时停顿一下 | 每字约 65 毫秒 |
| 按下按钮 | 轻微缩小到 0.97 | 0.15 秒 |

规矩：

- 不要给每个区块都加进场动画。
- 系统开了"减少动态效果"，所有动画关掉，直接出结果。

## 七、交互细节

- 所有可点的东西，点下去都要有反馈（缩放或变色）。
- 当前选中的状态要一眼能看出来：选中的卡片黑色描边加对勾，选中的标签底下有短横线。
- 不能用的选项变灰，并且用一句话说明为什么，比如"这杯只做冰的"。
- 不要弹窗。能原地展开的就原地展开。
- 键盘可以操作，焦点要看得见。

## 八、文案

所有界面文字都要：

- **短**。一句话能说完的，不写两句。
- **口语**。像咖啡师跟熟客说话，不像系统提示。
- **不说教**。不写"加油""一切都会好的""你值得"。
- **不用感叹号和 emoji**。

按钮写清楚点了会发生什么："帮我调一杯""就这杯""保存小票""再点一杯"。

报错也用同样的语气，并告诉用户怎么办。比如保存失败时写："没能保存，可以直接截图这张小票。"

参考现有文案：

| 场景 | 文案 |
|---|---|
| 点单页标题 | 此刻的你 / 适合哪一杯 |
| 点单页副标题 | 点几下就好，剩下的交给咖啡师。 |
| 倒咖啡时 | 正在萃取…… |
| 留言没写完时 | 咖啡好了，杯套还在写…… |
| 修改页还没改 | 想怎么改都行，我看着呢。 |
| 小票最后一行 | 谢谢光临，明天见 |
