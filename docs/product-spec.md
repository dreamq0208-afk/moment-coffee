# 产品方案

## 一、为什么做

现在大家的脑子每天被塞得很满。咖啡也慢慢变成了"牛马饲料"，喝它只是为了续命。

此刻咖啡馆想换个方式：用一杯咖啡，接住你此刻的心情。

它做三件事：

1. 根据你现在的状态，推荐一杯真能点到的咖啡。
2. 顺手把今天的心情记下来，几乎不用动脑子。
3. 给你一段"被看到"的留言，和一张能发出去的小票。

咖啡是主角。留言和小票是亮点。

## 二、给谁用

每天喝咖啡、事情很多、不想再多做一件费脑子的事的人。

主要场景：手机上打开，点几下，保存小票，发小红书。

## 三、完整流程

```
点单 → 出杯 → 看留言 →（不太对就改一下）→ 拿小票
```

整个过程只有一个杯子，一直在页面最上面。所有操作都发生在它下面。

### 1. 点单

三步，全是点选：

- **电量还剩多少**：五格电池，默认 3 格。每格对应一句话：快关机了、撑着呢、还行、挺有劲、满格。
- **现在是什么感觉**：选 1 到 3 个。累了、有点烦、焦虑、委屈、想哭、想被抱抱、孤单、平静、开心、有点期待、空空的、被夸了。选满三个后，其他的变灰。
- **想跟咖啡师说一句吗**：可以不写，最多 60 字。

一个感觉都没选时，按钮显示"先选一个感觉"，点不了。选了之后变成"帮我调一杯"。

### 2. 出杯

咖啡从杯口倒进去，一层层往上涨，大约 2.6 秒。倒完再出现冰块或热气，还有焦糖、海盐、可可粉、橙片、肉桂棒这些小料。

倒的同时，后台已经在写留言，不让用户干等。

倒完显示：

- **咖啡名字**：AI 起的，把心情和咖啡揉在一起。比如"撑住了燕麦拿铁"。
- **实际点法**：比如"燕麦拿铁，冰，少糖，单份浓缩，燕麦奶"。能拿去店里直接点。
- **为什么是这杯**：一句话。
- **「不太对，我改一下」**：一个小小的描边按钮。

### 3. 看留言

名字下面是一张牛皮纸杯套，留言一个字一个字手写出来。写完之后，小票才出现。

### 4. 改一下

点「不太对，我改一下」，进入修改状态。

- 页面不跳转。杯子缩小，但还在最上面。
- 杯子下面有一行手写字，是咖啡师对你改动的回应（见下方"心情回响"）。
- 再下面是咖啡的实时名字和配方，随着改动变化。
- 然后是五个标签：温度、甜度、浓度、奶、小料。
- 标签下面是选项卡片。
- 底部固定两个按钮：「换一杯」和「就这杯」。
- 左上角「不改了」：退回结果页，什么都不变。

**标签的规则**

- 每个标签下方显示当前值，比如"甜度 / 少糖"。
- 改过的标签右上角亮一个小橙点。改回原值，小橙点消失。

**选项卡片的规则**

- 每张卡片有：颜色圆点、名字、一句心情。
- 温度、甜度、浓度、奶是单选。小料可以多选，再点一次就拿掉。
- 冷萃和橙C美式只能做冰的。这时"热"变灰，下面写"这杯只做冰的"。
- 橙C美式加了奶，会自动变成普通的咖啡底，并拿掉橙片。

**杯子怎么跟着变**

每点一下，杯子马上变，不用等：

- 咖啡层、奶层平滑地变厚、变薄、变色，大约 0.45 秒。
- 冰块、热气、小料淡入淡出。

**咖啡名字怎么跟着变**

- 只改温度或甜度，名字不变。
- 改了奶、浓度或小料，名字按配方重新拼。比如牛奶 + 可可粉 + 海盐 = "海盐摩卡"。
- 拼名规则：`[风味前缀][冷萃][奶的叫法]`。风味前缀按海盐、焦糖、肉桂、橙香的优先级取一个。加了可可粉，"拿铁"变"摩卡"。不加奶就是"美式"或"冷萃"。

**心情回响（我们的特色）**

每改一下，杯子下面的手写字就更新，读出这个改动背后的心情。

- 显示最近两条，比如"想冷静一下，有点想哭。"
- 超过两条时，下面小字写"还有 N 个小心思，我也记着"。
- 改回原样，这条心情就撤掉。
- 还没改时写"想怎么改都行，我看着呢。"

**换一杯**

直接换成推荐排名里的下一杯，在前五名里循环。换完后心情回响显示"想换个口味"，之前的改动清空。

**就这杯**

- 什么都没改：等于"不改了"。
- 改过：回到结果页，杯子重新倒一遍，名字、理由、留言全部重新生成，小票更新。

### 5. 拿小票

热敏纸样式，上下锯齿边。内容：

- 店名、日期时间、单号
- 咖啡名字 ×1
- 实际点法、浓度和奶、加的小料
- 电量格子
- 此刻：选的感受
- 改动读出的心情（如果有）
- 用户写的那句话（如果有）
- 杯套留言
- "谢谢光临，明天见"

**小票只展示最终这杯。** 不显示推荐过什么、改了什么。

下面两个按钮：「保存小票」和「再点一杯」。

## 四、推荐规则

每个感受给不同的咖啡加分。第一个选的感受权重 1.2，其余 1。分最高的就是推荐，其余按分数排好，给"换一杯"用。

| 感受 | 加分 |
|---|---|
| 累了 | 馥芮白 +2，Dirty +2，燕麦拿铁 +1，冷萃 +1 |
| 有点烦 | 美式 +3，橙C美式 +2，冷萃 +1 |
| 焦虑 | 低因拿铁 +3，燕麦拿铁 +2，冷萃 −3，美式 −1 |
| 委屈 | 摩卡 +3，海盐焦糖拿铁 +2 |
| 想哭 | 海盐焦糖拿铁 +3，摩卡 +2 |
| 想被抱抱 | 摩卡 +3，燕麦拿铁 +2，低因拿铁 +1 |
| 孤单 | 生椰拿铁 +2，燕麦拿铁 +2，摩卡 +1 |
| 平静 | 馥芮白 +2，燕麦拿铁 +2，Dirty +1 |
| 开心 | 焦糖玛奇朵 +3，橙C美式 +2，生椰拿铁 +1 |
| 有点期待 | 橙C美式 +3，Dirty +2，焦糖玛奇朵 +1 |
| 空空的 | 冷萃 +2，美式 +2，馥芮白 +1 |
| 被夸了 | 焦糖玛奇朵 +2，Dirty +2，生椰拿铁 +1 |

再按下面几条调整：

- **电量 1–2 格**：馥芮白 +1。不是晚上的话，冷萃 +1，并给双份浓缩。
- **电量 4–5 格**：橙C美式 +1，焦糖玛奇朵 +1。
- **晚上 6 点到凌晨 5 点**：低因拿铁 +2，冷萃 −3，美式 −1，并且换成低因。
- **选了焦虑**：换成低因。
- **温度**：选了想被抱抱、孤单、委屈、想哭，能做热的就做热的。选了有点烦、焦虑（且没选前面那几个），能做冰的就做冰的。
- **甜度**：委屈、想哭、想被抱抱、孤单、开心、被夸了，选中两个及以上给半糖，一个给少糖。没选这些但选了有点烦或空空的，不加糖。其余少糖。

## 五、咖啡数据

| 咖啡 | 配方 | 可选温度 | 口感 | 咖啡因 | 适合什么时候 |
|---|---|---|---|---|---|
| 美式 | 不加奶 | 冰 / 热 | 苦得干脆，没有奶和糖 | 中 | 脑子乱、想清醒 |
| 燕麦拿铁 | 燕麦奶 | 冰 / 热 | 柔和，咖啡味不冲 | 中 | 想慢慢来 |
| 海盐焦糖拿铁 | 牛奶 + 海盐 + 焦糖 | 热 / 冰 | 一点咸一点甜 | 中 | 情绪有点满 |
| 摩卡 | 牛奶 + 可可粉 | 热 / 冰 | 巧克力托底，偏甜 | 中 | 需要被哄一下 |
| 焦糖玛奇朵 | 牛奶 + 焦糖 | 冰 / 热 | 第一口就是甜的 | 中 | 有好事的时候 |
| 馥芮白 | 牛奶 | 只有热 | 奶少咖啡多，很顺 | 中偏高 | 累了但还得撑 |
| 橙C美式 | 橙汁 + 浓缩 + 橙片 | 只有冰 | 酸甜把苦味提亮 | 中 | 想要点精神 |
| 低因拿铁 | 牛奶 + 低因 | 热 / 冰 | 和拿铁差不多，更温和 | 很低 | 晚上、心慌的时候 |
| 冷萃 | 不加奶 | 只有冰 | 不酸不苦，很安静 | 高 | 白天需要放空 |
| 生椰拿铁 | 椰乳 | 只有冰 | 椰乳淡甜 | 中 | 一个人的时候 |
| Dirty | 冰牛奶 + 浓缩 | 只有冰（不加冰块） | 冰牛奶上浮一层浓缩 | 中偏高 | 想来点小刺激 |

咖啡因只写"很低、中、高"这种档位。不同店差别很大，写具体毫克数反而不准。

## 六、修改选项

每个选项都带一句心情。它既显示在卡片上，也是"心情回响"和 AI 留言的依据。

| 分类 | 选项 | 心情 |
|---|---|---|
| 温度 | 冰 | 想冷静一下 |
| 温度 | 热 | 想被暖一暖 |
| 甜度 | 不加糖 | 不想被哄 |
| 甜度 | 少糖 | 一点点就好 |
| 甜度 | 半糖 | 想被照顾一下 |
| 甜度 | 标准糖 | 今天需要甜的 |
| 浓度 | 单份浓缩 | 刚刚好就好 |

| 浓度 | 低因 | 想让自己慢下来 |
| 奶 | 牛奶 | 想要熟悉的味道 |
| 奶 | 燕麦奶 | 想温柔一点 |
| 奶 | 椰乳 | 想轻松一点 |
| 奶 | 不加奶 | 想要干脆一点 |
| 小料 | 海盐 | 有点想哭 |

## 七、以后再做

这些都需要记录历史，等核心玩法稳了再做：

- **咖啡图鉴**：每喝到一种新咖啡点亮一格，点满有一张特别的小票。
- **点单记录**：一周七张小票排在一起，就是一周的心情。
- **月底咖啡渍日历**：每天一个咖啡杯印，颜色深浅代表情绪浓度。
